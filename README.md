
# صفحة بيضاء — كويز كنسي

موقع كنسي بتصميم هادئ مستوحى من فكرة "صفحة بيضاء"، ويعمل بنظام:
**أول شخص يدخل يأخذ الموقع، والباقي ينتظرون تلقائيًا.**

## التشغيل على الكمبيوتر

1. ثبّت Node.js.
2. افتح Terminal داخل مجلد المشروع.
3. نفّذ:

```bash
npm install
npm start
```

4. افتح:
`http://localhost:3000`

## السؤال

السؤال الحالي:
"مين هو صاحب شخصية الكنز؟"

أ. موسى  
ب. دانيال  
ج. داود  
د. إيليا

الإجابة الصحيحة مضبوطة حاليًا على **د. إيليا** داخل `public/app.js`.
لو الإجابة الصحيحة مختلفة عندك، غيّر قيمة `CORRECT_ANSWER`.

## نشره كرابط للناس

المشروع يحتاج استضافة تدعم Node.js لأن نظام "شخص واحد في نفس الوقت" يعمل على السيرفر.
يمكن رفعه على أي خدمة استضافة Node.js، ثم مشاركة رابط الموقع الناتج مع الناس.

مهم: رابط `localhost` يعمل على جهازك فقط وليس رابطًا عامًا.
